# Tailwind Mini Projects

First Tailwind CSS exercises using the Tailwind CLI: a card layout and a login form (`src/assets/pages/`).

تمرین‌های اولیهٔ Tailwind CSS.

## Run
```bash
npm install
npx @tailwindcss/cli -i ./src/input.css -o ./src/output.css --watch
```
Then open the HTML pages in a browser.
